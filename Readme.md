# 多模态乳腺超声分子亚型分类网络：全栈架构设计与系统工程实现

## 1. 项目背景与动机
乳腺癌分子亚型的精准分型（Luminal A, Luminal B, HER2+, TNBC）对临床方案制定至关重要。本项目旨在通过**非侵入性**的手法，利用多模态超声影像（BUS、SWE、CDFI）与临床文本报告，构建一个端到端的深度学习分类网络。

### 核心挑战
* **数据稀缺性**：医学影像标注成本极高，样本量有限（约800例）。
* **模态异构性**：如何有效融合解剖结构（BUS）、物理硬度（SWE）、血流动力学（CDFI）及高阶语义（Text）。
* **捷径学习**：防止模型过度依赖文本关键词而忽略影像特征。

---

## 2. 核心技术栈与基础模型
系统采用模块化设计，结合了视觉基础模型与参数高效微调（PEFT）技术：

| 技术组件 | 选型 | 优势 |
| :--- | :--- | :--- |
| **视觉骨干网络** | **TinyUSFM** | 5.5M极轻量化，针对超声模态定制，抗斑点噪声力强。 |
| **血流特征融合** | **IP-Adapter** | 解耦交叉注意力机制，将CDFI作为"软提示"注入，不破坏原有表征。 |
| **文本编码器** | **BioClinicalBERT** | 深度理解医学领域专属缩写与复杂病型描述。 |
| **文本微调技术** | **LoRA ($r=8$)** | 仅需极少量参数更新（<0.02%）即可实现领域自适应。 |

---

## 3. 第一阶段：空间对齐跨模态掩码重建 (ACM-MIM)
此阶段为自监督预训练，通过"填空题"任务强迫模型学习解剖与硬度模态间的内在规律。

### 输入处理
将原始 BUS 图像（解剖结构）与同平面 SWE 图像（物理硬度）在**通道维度堆叠**（形成 4 通道输入），切分为 **16×16 的补丁序列**。

### 掩码策略设计
系统采用**非对称掩码**：
* **BUS (解剖)**：75% 随机掩码，作为重建目标。
* **SWE (硬度)**：0% 掩码（完全保留），作为推理锚点。

### 可训练编码器 (Updated TinyUSFM)
采用 TinyUSFM（5.5M 参数）作为编码器。**在此阶段，该模型是可训练的**，目标是利用 SWE 提供的硬度信息（如高杨氏模量点）来重建缺失的 BUS 组织结构。

### 物理学逻辑
模型必须通过 SWE 的高硬度区域（杨氏模量分布）去推断 BUS 中可能存在的边缘毛刺或后方衰减，强制建立"硬度-形态"的深层物理关联。这是最核心的物理先验挖掘步骤——模型必须"根据硬度分布来推测解剖征象"（例如：SWE 显示极硬的点，通常对应 BUS 上的边缘毛刺征），从而在无标注数据上获得极强的特征判别性，而非死记硬背像素分布。

### 重建损失
通过轻量级解码器恢复完整 BUS 图像，计算重建损失：

$$L_{recon} = \frac{1}{|M|} \sum_{i \in M} \| \hat{Y}_{BUS}^{(i)} - Y_{BUS}^{(i)} \|_2^2$$

## 4. 第二阶段：语义增强对比分型 (SEC-Subtyping)
此阶段利用已加载预训练权重的模型进行多模态分类微调。

### 权重加载与冻结
将第一阶段训练好的 TinyUSFM 权重加载至分型任务，并将其**完全冻结**。在 800 例样本规模下，冻结主干可有效防止过拟合，保留预训练获得的稳健表征。

### 4.1 模态支路设计

1. **BUS & SWE 分支**：原始 BUS 与原始 SWE 经 Joint Patch Embedding 模块（内部执行 `torch.cat([bus, swe], dim=1)` 通道堆叠，`Conv2d(in_channels=4, ...)` 与 Stage 1 结构完全一致）生成 patch tokens，连同 [CLS] token 一起进入 Frozen TinyUSFM。编码器完成全部 12 层前传后，从输出中切取 [CLS] token 作为全局特征 $F_{bus\_swe}$（形态 $B \times 192$）。
   - 两个阶段的 Patch Embedding 层参数结构完全一致，确保 Stage 2 可无缝加载 Stage 1 预训练权重。两者空间严格对齐的"重合"输入能确保模型从底层像素级开始，就学习到特定位置的声学回声与杨氏模量的对应关系，消除模型自主寻找对齐关系的计算负担，大幅降低小样本下的收敛难度。

2. **CDFI 分支**：CDFI 图像经 MobileNetV2 浅层架构提取空间特征图（$B \times C_{cnn} \times H' \times W'$），再经 Projection Layer 拉平并映射为 **CDFI Tokens**（$B \times N_{cdfi} \times 192$，维度与 TinyUSFM 对齐）。这些 CDFI Tokens 与 [CLS] token 及 BUS+SWE patch tokens 一同进入 TinyUSFM 前传；在 **第 6-11 层**，IP-Adapter 的解耦交叉注意力机制以编码器内部所有 tokens 为 Query、CDFI Tokens 为 Key/Value，使 [CLS] token 逐层吸收血流信息。因此 $F_{bus\_swe}$ 在提取时已包含 CDFI 语义。
   - CDFI 反映的是血流分布，不一定与组织物理边界实时严格对应。使用 Adapter 可以在不干扰 BUS-SWE 稳固几何表征的前提下，将"血流丰富程度"作为一种补充判别信号注入决策过程。

3. **文本分支**：通过集成 **LoRA** 的 BioClinicalBERT 提取临床语义特征 $F_{text}$。
   - 临床描述包含高阶诊断逻辑。通过 LoRA 微调，使语言模型能识别特定亚型的关键词，为最终分类提供统计学先验依据。

### 4.2 跨模态特征融合
图像与文本特征通过 **LightweightCrossAttention** 模块进行融合（Q=图像, KV=文本），使文本临床语义动态调制图像表征。融合后特征维度为 $\text{image\_dim} + 512$，送入分类头。

### 4.3 对比对齐模块 (CAM)
在 **512 维潜空间**内计算图像混合特征与文本向量的 InfoNCE 对比损失 $L_{align}$，消除模型对文本关键词的"捷径学习"。CAM 仅作为训练正则化项，不参与推理时特征融合。也可采用去偏 InfoNCE 损失防止"假阴性"惩罚，使相同亚型的病人在潜空间中自然聚类。

**对齐损失 ($L_{align}$):**
$$L_{align} = - \log \frac{\exp(sim(I_i, T_i) / \tau)}{\exp(sim(I_i, T_i) / \tau) + \sum_{j \neq i} \exp(sim(I_i, T_j) / \tau)}$$

**去偏变体：** 引入基于类别先验的校正因子 $q_{ij}$：
$$L_{align}^{debiased} = - \log \frac{\exp(sim(I_i, T_i) / \tau)}{\exp(sim(I_i, T_i) / \tau) + \sum_{j \neq i} q_{ij} \exp(sim(I_i, T_j) / \tau)}$$

### 4.4 四分类决策头
最终通过 MLP 输出四种分子亚型的概率分布，输入为 LightweightCrossAttention 融合后的特征（维度 $\text{image\_dim} + 512$）。

## 6. 联合优化目标
模型通过加权多任务损失函数进行端到端优化：

$$L_{total} = \alpha L_{cls} + \beta L_{align}$$

其中 **类别加权交叉熵损失 ($L_{cls}$)** 用于解决样本不平衡问题：
$$L_{cls} = - \sum_{i=1}^{4} W_i \cdot y_i \log(\hat{y}_i)$$
* $W_i$：少数派类别加权系数。
* $\hat{y}_i$：分类预测概率。
