# 2026-09-01 全测试集 SWE 置乱实验结果

## 实验目的

本实验在已核实的 82 例恶性测试集上，对比原始输入与 SWE 循环错配条件下的四分类表现，检验模型整体指标和类别决策对 SWE 内容配对的敏感性。实验不重新训练模型，不修改标签或数据划分。

远端定向测试结果为 `17 passed in 3.47s`。完整审计包含 82 条病例记录，输出仅保留脱敏统计。既有条件四分类基线指标与本次原始条件一致，说明评估口径和检查点恢复正确。

## 实验条件

- **原始输入**：每例使用其原有的 BUS、SWE、CDFI 和文本输入。
- **SWE 循环错配**：保持病例标签及其他输入不变，将 SWE 输入按测试集病例顺序循环移位后再进行推理。
- **类别顺序**：所有逐类指标、混淆矩阵和预测分布均按 `Luminal A、Luminal B、HER2+、TNBC` 排列。

| --- | ---: | ---: | ---: |

## 混淆矩阵

矩阵行是真实类别，列是预测类别；行列顺序均为 `Luminal A、Luminal B、HER2+、TNBC`。

### 原始输入

```text
[[10, 0,  7, 1],
 [ 8, 0, 12, 0],
 [10, 0, 21, 0],
 [ 1, 0, 12, 0]]
```

### SWE 循环错配

```text
[[ 9, 0,  8, 1],
 [ 7, 0, 12, 1],
 [ 9, 0, 22, 0],
 [ 1, 0, 12, 0]]
```

两种条件下 Luminal B 和 TNBC 的预测仍为零；错配后 Luminal A 与 HER2+ 之间的局部计数发生小幅变化，但没有改变整体 Accuracy。

## 预测分布与改变率

| 条件 | Luminal A | Luminal B | HER2+ | TNBC | 合计 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原始输入 | 29 | 0 | 52 | 1 | 82 |
| SWE 循环错配 | 26 | 0 | 54 | 2 | 82 |

两种条件逐例比较时，共有 `7/82` 例的预测类别发生改变，预测改变率为 `8.5366%`。改变主要体现在既有 Luminal A、HER2+ 和少量 TNBC 输出之间的重新分配，并未使模型开始输出 Luminal B。

## 结果解释

SWE 循环错配没有造成明显的整体指标下降：Accuracy 保持 `0.3780487805`，Macro-F1 仅下降 `0.0012045108`，Balanced Accuracy 下降 `0.0058243728`。同时，HER2+ 的 F1 小幅上升，Luminal A 的 F1 小幅下降，另外两类保持为零。因此，在本次全测试集审计范围内，不能据此支持当前模型存在稳定、强的 SWE 病例内容依赖。更谨慎的解释是，模型的主要决策已被现有类别塌缩和其他模态表征主导，SWE 配对变化只改变了少数边界样本的输出。

这一结果不等同于病灶定位证据，也不提供因果证据。错配实验只检验病例级配对扰动下的预测稳定性，不能说明模型是否在 SWE 图像中关注了真实病灶，更不能单凭整体指标近似不变就断言 SWE 没有任何有用信息。

## 数据边界与局限性

- 测试集为 82 例恶性病例，亚型分布为：Luminal A `18` 例、Luminal B `20` 例、HER2+ `31` 例、TNBC `13` 例。
- 该审计依赖单次已核实的全测试集运行和一次 SWE 循环错配，未覆盖不同随机置乱、不同随机种子或重复推理，因此不能估计更广泛的错配方差。
- 当前没有独立的患者级去重信息，不能把这 82 例直接表述为已完成患者级独立测试；结果可能受同源病例或病例组结构影响。
- 预测分布对 Luminal B 和 TNBC 的塌缩仍然明显，整体指标的稳定不代表四类分型能力均衡。
- 本实验没有病灶 ROI、定位标注或因果干预设计，不能外推为病灶定位能力、临床有效性或模态因果贡献。

## 唯一首选下一步

后续模型设计重点转向 BUS+Text 主干，并对 SWE 采用受控残差注入，或在训练中加入模态缺失/错配鲁棒性约束；暂不开展新的大规模 SWE 结构搜索。
