# 2026-08-09 B1 固定检查点模态消融结果（阶段 A）

## 实验目的与固定条件

本轮实验的目的，是在**同一份完整 B1 五分类模型、同一份已训练权重、同一批恶性测试病例**上，通过推理期输入屏蔽（modality ablation）观察模型对不同模态的依赖方式，为下一阶段“独立训练的模态组合”排序提供诊断依据。

固定条件如下：

- 代码版本：`8d5b22b3448d97d2411a84fea3a5576798e696c9`
- 当前分支：`exp/reliable-stage2-baselines`
- 远端结果目录：`anon-service2:/data/lzj813/b1-modality-probe-20260809-8d5b22b`
- 五组实验均基于**同一完整模型的固定权重**做推理期输入屏蔽，不重新训练。
- 五组均为恶性条件四分类审计，`record_count=82`。
- 四分类类别顺序均为：`[Luminal A, Luminal B, HER2+, TNBC]`。
- `full` 组 `verify_saved_metrics=true`；四个 ablation 组均为 `verify_saved_metrics=false`，表示本次读取到的是现有产物摘要，未在本任务中重跑保存指标复核。

**必须强调：**这是一组“同一完整模型固定权重下的输入屏蔽依赖诊断”，**不等于**重新训练后的 BUS-only、SWE-only、去文本或去 CDFI 模型的正式性能，也**不能**据此证明单模态的因果贡献。

## 诊断性解释

### 1. 去掉文本后出现最明显下降

`without-text` 的 Macro-F1 从 `0.2329` 降到 `0.1308`，Balanced Accuracy 从 `0.3082` 降到 `0.2258`，是五组里最明显的整体退化。其退化方式不是“大量掉到良性”，因为恶性误判为良性只有 `2/82`；更突出的现象是条件四分类头几乎塌缩到 `HER2+`，预测分布变成 `[6, 0, 76, 0]`，同时 `Luminal A`、`Luminal B`、`TNBC` 三类召回全部归零。

这说明在当前固定权重下，文本模态对恶性亚型边界，尤其是把非 `HER2+` 病例从 `HER2+` 吸引盆里拉出来，作用最大。它应被视为下一阶段独立训练组合中的高优先级保留项。

### 2. 去掉 SWE 表现为中度下降，但错误机制最极端

`without-swe` 的 Macro-F1 降到 `0.2087`，Balanced Accuracy 降到 `0.2769`，按总体指标看属于中度下降；但其错误机制与其它组明显不同。条件四分类头仍大量输出恶性类别，且 `HER2+` 召回反而升到 `0.7742`，然而端到端五分类里有 `67/82` 个恶性病例被主头判成了良性。

也就是说，去掉 SWE 后的主要问题不只是亚型之间的混淆，而是恶性/良性主判别门控显著失稳。这个现象提示：SWE 在当前 checkpoint 中可能更深地参与了“先判恶性、再细分亚型”的链路，而不是仅仅提供亚型纹理补充。

### 3. 去掉 CDFI 几乎不变

`without-cdfi` 与 `full` 在 Macro-F1、Balanced Accuracy、Accuracy、四类召回、条件预测分布和错误类型计数上都几乎完全一致；在本次远端摘要中可以视为“基本不变”。

但这**不能**被解释为 “CDFI 无用”。更谨慎的解释是：在这个固定权重、这个实现方式、这 82 个恶性病例上，模型当前没有表现出对 CDFI 的明显依赖；如果改成独立训练、重新校准融合层或更换数据切片，结论仍可能改变。

### 4. 去掉 BUS 反而略升，但不能据此宣称 BUS 无用

`without-bus` 的 Macro-F1 升到 `0.2514`，Balanced Accuracy 升到 `0.3163`，Accuracy 升到 `0.3902`，恶性误判为良性从 `3` 降到 `1`。从这组固定权重诊断看，去掉 BUS 后，当前模型在这 82 例上的表现确实略好。

但这同样**不能**被过度解读为 “BUS 无用” 或 “去掉 BUS 一定更好”。更合理的解释至少包括：

- 固定权重下存在融合失配，BUS 分支可能把已经学偏的证据再次放大；
- 屏蔽实现改变了归一化或融合张量的分布，改善并不等价于重新训练后的最优组合；
- 82 例恶性样本的分布有限，可能放大了局部数据切片效应。

因此，这一结果只适合作为**下一阶段独立训练组合优先级**的线索，而不是对 BUS 模态价值的定论。

### 5. 基线本身已存在明显的亚型塌缩问题

无论是否消融，五组里 `Luminal B` 召回始终为 `0.0000`，条件头也从未输出过 `Luminal B`；TNBC 召回也始终为 `0.0000`。这说明阶段 A 的固定 checkpoint 本身已经存在明显的类别边界塌缩，而模态消融只是把这种塌缩以不同方式放大或转移。

因此，不能把本页结果直接理解成“单模态重要性排名”；它更接近“在一个已有偏置的融合模型里，去掉某个输入后，错误会往哪里流”。

## 限制与下一步

### 限制

1. 本结果来自**同一完整模型固定权重下的输入屏蔽**，不是各模态组合的独立训练结果。
2. 本结果不证明单模态的因果贡献，也不提供 BUS-only、SWE-only 等正式模型性能结论。
3. 样本仅包含 `82` 例恶性病例，且当前 checkpoint 本身已经对 `Luminal B` 和 `TNBC` 表现出严重塌缩。
4. 四个 ablation 组 `verify_saved_metrics=false`，因此本文应视为“远端现有产物整理稿”，不应替代后续正式复核。

### 下一步

1. 将本页结论仅用于**阶段 B 独立训练组合的优先级排序**：文本模态优先保留，SWE 相关组合优先复核，CDFI 可暂列低优先级对照，BUS 去留必须通过独立训练而非固定权重消融来判断。
2. 对 `without-swe` 单独补做恶性/良性主头的门控分析，确认为何出现 `67/82` 的恶性落入良性。
3. 对 `Luminal B` 与 `TNBC` 的长期召回为零问题，优先做类别边界与训练采样诊断，而不是把责任简单归因到某一个模态。
4. 若该页后续进入论文材料或正式实验账本，应在同一提交、同一 checkpoint 下重新补齐四个 ablation 组的保存指标复核。

## 结论

作为阶段 A 的固定检查点模态依赖诊断，可以给出一条谨慎而有用的工作结论：**去掉文本导致明显下降，去掉 SWE 中度下降，去掉 CDFI 几乎不变，去掉 BUS 反而略升。**

但这条结论只适合指导“下一阶段优先重训哪些模态组合”，**不等于**这些组合在独立训练后的正式优劣，也**不证明**某个单模态对结果具有直接因果贡献。
