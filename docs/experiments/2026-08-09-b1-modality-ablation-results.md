## 结果讨论

### 1. 直接删除 SWE/CDFI 的 `bus-only` 和 `bus-cdfi` 出现了明显预测坍缩

`bus-only` 与 `bus-cdfi` 的测试集指标完全相同，预测分布都塌缩为 `[0, 0, 82, 0]`，即把全部 82 例都压到 `HER2+`。这说明在当前设置下，单独保留 BUS，或者只保留 BUS+CDFI，都无法维持四类边界。

### 2. `bus-swe` 没有带来改善

`bus-swe` 没有恢复 `Luminal B`，Balanced Accuracy 也只有 `0.227909`，低于 `full`。它虽然不再像 `bus-only` 那样完全塌到单一类别，但验证集与测试集都没有显示出足够清晰的改善信号，因此本轮不应视为候选。

### 3. 去掉图像附加模态、保留文本的 `bus-text` 在验证集有改善，但测试集仍不完整

`bus-text` 的验证集 Macro-F1=`0.316708`、Balanced Accuracy=`0.320894`，四类 Recall 全部非零，是本轮唯一达到候选门槛的组合。测试集上它也确实恢复了 `Luminal B` 召回（`0.25`），预测分布从 `full` 的 `[29, 0, 52, 1]` 变成了 `[31, 20, 20, 11]`，说明它至少部分缓解了“只压向 `HER2+`”的结构性偏置。

但这个结果仍然不能过度解读：

- `TNBC` 测试召回仍然是 `0`；
- 它的 Accuracy=`0.268293`，明显低于 `full` 的 `0.378049`；
- 它的 Balanced Accuracy=`0.257841`，也低于 `full` 的 `0.308244`；
- 它与 `full` 的测试 Macro-F1 只差 `0.000279`，在单 seed 下远不足以支持“优于 full”的结论。

因此，更准确的表述是：`bus-text` 是下一步应该继续复验的**候选组合**，而不是已经被证明优于 `full` 的最终方案。

### 4. 这一轮结果只能支持谨慎的工作判断，不能推出因果或泛化结论

本页只是固定切分、单 seed=`42`、82 例恶性测试集上的正式训练整理。它可以帮助决定“下一步先复验哪个组合”，但不能据此推出：

- 某个模态对结果具有单独的因果贡献；
- `bus-text` 在总体上优于 `full`；
- 这些趋势必然会在其它 seed、其它切分或更大样本上保持不变。

## 限制

1. 当前结果只覆盖固定切分、单 seed=`42`、82 例恶性测试集，证据规模有限。
2. 本页直接采用已核对正式结果做整理，不回放完整训练日志，也不据此反推所有中间轮次细节。
3. `bus-text` 的测试 Macro-F1 虽与 `full` 接近，但 Accuracy 与 Balanced Accuracy 均未超过 `full`，因此不能据单次测试宣称其更优。
4. `bus-only` 与 `bus-cdfi` 已表现出明显预测坍缩，但这仍然只是当前设置下的观察，不应外推成脱离上下文的因果定论。

## 下一步

当前最稳妥的执行结论是：

1. `bus-only` 与 `bus-cdfi` 不应继续投入，当前结果表现为明显预测坍缩。
2. `bus-swe` 本轮未见改善，也不进入下一步多 seed 复验。
3. `bus-text` 是唯一值得继续追的**候选组合**，但必须补做 `seed=3407` 与 `seed=2026`。
4. 在多 seed 复验完成前，不宣称任何组合优于 `full`。

如果后续需要写入更正式的论文账本或“非正式多模态最终结论”，边界也应保持一致：目前只允许说“`bus-text` 值得复验”，不允许说“文本+BUS 已经优于完整四模态”。
