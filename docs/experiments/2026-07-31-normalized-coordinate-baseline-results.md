# 归一化坐标对齐后的 Stage 2 基线结果

## 实验目的

原始 BUS 与 SWE 图像常具有不同的像素尺寸，严格要求原始像素网格一致会使部分样本无法进入 Stage 2。该轮实验将二者各自映射到共同的归一化坐标网格；训练时先映射到 258 x 258 网格，再共享随机裁剪、翻转和旋转，最终输入 224 x 224。该处理只保证近似的归一化空间一致性，不代表原始像素级配准。

代码版本为 `0c71b7c`，随机种子为 42，训练轮数为 100，批大小为 8，学习率为 5e-4，权重衰减为 0.05，解冻层数为 2。

## 可比性审计

- 三组均已生成 `best_model.pth`、`metrics_best.json`、`metrics_test.json` 与 `split_manifest.json`。
- B1 与 B2 的训练、验证和测试 case ID 完全一致：训练 725 例，恶性验证 151 例，恶性测试 82 例，二分类验证 192 例，二分类测试 124 例。
- B0 的恶性验证与测试 case ID 与 B1/B2 完全一致，但其训练集仅包含恶性四分类样本，共 534 例；因此 B0 是条件四分类参考基线，B1 与 B2 才是严格同训练集的直接比较。
- B2 的最优检查点进行了两次独立重复评估。两份结果文件逐字节一致，且与训练结束时的恶性分型 Accuracy、Balanced Accuracy、Macro-F1、混淆矩阵和预测分布完全一致。

## 结果

| 实验 | 运行目录 | 恶性条件 Macro-F1 | 恶性条件 Balanced Accuracy | 恶性预测分布 | 二分类 Macro-F1 | 二分类 AUC |
| --- | --- | ---: | ---: | --- | ---: | ---: |
| B0：仅恶性四分类 | `flat4_20260731-232334` | 0.2177 | 0.2915 | [0, 41, 41, 0] | 不适用 | 不适用 |
| B1：端到端五分类 | `flat5_20260731-232334` | 0.2329 | 0.3082 | [29, 0, 52, 1] | 0.8776 | 0.9355 |
| B2：二分类与四分类双头 | `dual_head_20260731-232334` | 0.1454 | 0.1827 | [4, 18, 54, 6] | 0.8893 | 0.9434 |

恶性四分类顺序为 Luminal A、Luminal B、HER2+、TNBC。B0 只预测 Luminal B 与 HER2+；B1 的 Luminal B 和 TNBC 召回均为 0；B2 虽输出四种类别，但 Luminal A 与 TNBC 召回仍为 0。B2 相对 B1 的二分类 AUC 增加 0.0078、二分类 Macro-F1 增加 0.0117，但恶性条件 Macro-F1 下降 0.0875，说明良恶性辅助监督没有转化为分子分型边界的改善。

## 本轮结论

1. 归一化坐标对齐已消除 BUS/SWE 原始尺寸不一致导致的运行失败，三组实验均能完整训练和评估。
2. 该处理本身没有解决分子分型中的类别塌缩问题，不能据此声称分型性能提升。
3. B2 未达到超过 B0 和 B1 的预设候选标准，因此不开展其多种子复验，也不作为论文主方法候选。
4. 后续实验应固定 B1 的数据切分与归一化坐标处理，只修改一个与恶性四分类类别不平衡直接相关的训练变量，并以恶性条件 Macro-F1、四类 Recall 和预测分布作为主判据；二分类提升不能替代分型提升。
