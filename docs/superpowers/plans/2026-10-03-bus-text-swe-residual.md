# BUS+Text 与 SWE 残差成对实验实施计划

> **执行约束：** 当前设计已由用户批准。按测试先行、代码复核、远端独立目录复跑的顺序执行。

**目标：** 用最少训练判断轻量 SWE 残差是否能在固定协议下改善恶性四分类。

**结构：** 在既有 Stage 2 模型中新增两种成对模式，复用训练、损失、选模、复评与数据划分链路。

**技术栈：** PyTorch、pytest、现有 TinyUSFM 和 BioClinicalBERT。

## 全局约束

- 所有新增 Markdown、注释、文档字符串和命令行提示使用中文。
- 不修改旧模式默认行为，不增加新损失、采样策略或 CDFI 融合。
- 远端缓存及产物仅写入 `/data`；不覆盖既有远端未提交改动。
- 首先只跑 seed 42 成对试验；是否补多种子由验证集结果决定。

## 任务 1：模型与训练入口

**文件：** `code/models/stage2/subtyping_model.py`、新增 `code/models/stage2/swe_residual.py`、`code/train/train_stage2.py`、`code/tests/test_stage2.py`、`code/tests/test_train_stage2.py`。

1. 先写失败测试：BUS+Text 输出对 SWE/CDFI 输入变化不敏感；残差组输出对 SWE 变化敏感且对 CDFI 不敏感；残差分支得到梯度；旧默认模式的形状与参数不变。
2. 为训练入口写失败测试：新模式仅接受 `flat5`，构建模型后优化器准确包含残差分支参数，额外参数初始化不会改变成对训练顺序，训练结束不自动评估测试集，检查点复评恢复已保存的模式。
3. 最小实现：主干始终以零 SWE 通道提取 BUS 特征；实验组经轻量 CNN 提取 SWE 特征，以有界系数残差注入；旧模式保留原前传。
4. 运行定向测试、全量测试和差异检查，修复实际失败后提交。
