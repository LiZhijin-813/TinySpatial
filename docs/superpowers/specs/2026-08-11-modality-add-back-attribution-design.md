# SWE/CDFI 逐一加回模态归因实验设计

## 目标

在现有 `BUS+Text` 与 `Full` 结果之间补齐最小必要对照，判断 SWE、CDFI 中哪一种模态主要贡献了 Luminal A 与 Luminal B 的可分性提升。

本实验只回答模态增量贡献问题，不同时引入新分类头、新损失函数或新融合结构，避免多个变量共同变化后无法解释结果。

## 当前证据

现有病例组五折层级探针显示：

- `BUS+Text` 的 Luminal A/B Macro-F1 为 `0.5167`，Balanced Accuracy 为 `0.5416`。
- `Full` 的 Luminal A/B Macro-F1 为 `0.5691`，Balanced Accuracy 为 `0.5719`。
- `Full` 在 Luminal/non-Luminal 和 HER2+/TNBC 两个边界上没有稳定超过 `BUS+Text`。

但远端参数复核发现，这两个检查点并非同协议训练：`BUS+Text` 使用 `unfreeze=0` 和无类别权重，全模态使用 `unfreeze=2`、逆频率类别权重和 `patience=50`。因此，上述差异只能作为待复核线索，不能直接归因于 SWE 与 CDFI。

正式逐一加回实验前，必须先对阶段 B 中同为 `seed=42`、`unfreeze=2`、`patience=20`、逆频率类别权重的 `bus-text` 与 `full` 已有检查点补跑层级探针。只有 Luminal A/B 差异在同协议对照中继续存在，才进入新增训练。

## 实验组

保留两个已有对照，只新增两个训练配置：

| 配置 | 输入模态 | 状态 | 目的 |
| --- | --- | --- | --- |
| `bus-text` | BUS、Text | 已有同协议检查点 | 增量比较基线 |
| `bus-text-swe` | BUS、Text、SWE | 新增 | 测量 SWE 的增量贡献 |
| `bus-text-cdfi` | BUS、Text、CDFI | 新增 | 测量 CDFI 的增量贡献 |
| `full` | BUS、Text、SWE、CDFI | 已有同协议检查点 | 联合模态对照 |

不增加 SWE-only、CDFI-only、SWE+CDFI 或更多排列组合。单模态归因由上述两个逐一加回配置完成。

## 固定条件

两个新增配置必须与现有阶段 B 独立训练保持一致：

- 使用相同数据版本、病例级训练/验证/测试切分与标签映射。
- 使用相同预训练权重、随机种子 `42`、数据增强和优化器配置。
- 使用相同训练上限、早停耐心值和 `malignant_macro_f1` 选模指标。
- 除输入模态开关外，不改变网络结构、损失函数、采样策略或融合参数。
- 筛选阶段不根据测试集结果选择配置。

## 执行流程

1. 对阶段 B 已有的同协议 `bus-text` 和 `full` 检查点运行层级探针，完成可比性门禁。
2. 若同协议 `full` 相对 `bus-text` 的 Luminal A/B 五折平均 Macro-F1 提升不足 `0.03`，或少于四折方向一致，则立即停止，不启动新增深度训练。
3. 门禁通过后，独立训练 `bus-text-swe` 和 `bus-text-cdfi`，每个配置仅运行 `seed=42` 一次。
4. 汇总验证集恶性四分类 Macro-F1、Balanced Accuracy 和四类召回率。
5. 对两个新增检查点运行现有病例组五折层级特征探针，重点读取 Luminal A/B 指标，同时保留另外两个层级作为退化检查。
6. 将四个同协议配置放入一张表中，不在本轮增加新的模型分支。
7. 只有满足晋级规则的单个配置进入后续多种子复验；若均不满足，则本轮停止，不继续扩展模态组合。

层级特征探针属于表示能力诊断，不作为最终模型泛化性能。正式模型结论仍以独立验证和最终测试协议为准。

## 主要指标与晋级规则

主要诊断指标为 Luminal A/B 的五折 Macro-F1 与 Balanced Accuracy。辅助约束为验证集恶性四分类 Macro-F1，以及 Luminal/non-Luminal、HER2+/TNBC 两个层级是否明显退化。

一个新增配置只有同时满足以下条件才晋级：

1. 相对 `bus-text`，Luminal A/B 五折平均 Macro-F1 提升至少 `0.03`。
2. 五折中至少四折的 Luminal A/B Macro-F1 不低于 `bus-text` 对应折。
3. 验证集恶性四分类 Macro-F1 相对 `bus-text` 的下降不超过 `0.01`。
4. 另外两个层级未出现预测坍缩或明显的单类偏置。

若 SWE 与 CDFI 均满足条件，只选择 Luminal A/B Macro-F1 提升更大者进入复验，不同时推进两个候选。

## 结果解释

- 若只有 `bus-text-swe` 晋级，说明 SWE 是当前 Luminal A/B 增量信息的主要来源。
- 若只有 `bus-text-cdfi` 晋级，说明 CDFI 是主要来源。
- 若两者均有提升但都弱于 `full`，说明 SWE 与 CDFI 可能存在互补作用，但本阶段仍只选择表现更稳定的单个配置继续。
- 若两者均未晋级，则停止模态排列实验，认为当前 `Full` 与 `BUS+Text` 的差异不足以归因于单一模态，后续转向任务条件化或表示学习目标。

## 输出产物

- 两个新增配置的训练目录与固定检查点。
- 两个已有同协议基线的层级探针结果。
- 验证集四分类指标汇总。
- 两个新增配置的 `hierarchical_probe_metrics.json`。
- 一份四配置对照结果文档，记录实验条件、逐折指标、晋级判断和下一步结论。

不在 Git 仓库中提交模型权重、训练缓存或大体积中间特征。

## 验证要求

- 新增配置必须通过现有参数解析和数据加载测试。
- 启动训练前核对实际启用模态与配置名称一致。
- 每个结果目录必须记录提交哈希、随机种子、切分清单、最佳轮次和检查点路径。
- 层级探针必须继续执行病例组跨折校验，并输出有效样本数与各折查询样本数。
- 结果汇总只使用真实生成的 JSON，不手工改写原始指标。

## 计算约束

本轮先运行两次同协议基线的轻量层级探针。可比性门禁通过后，最多新增两次单种子深度训练和两次轻量层级探针；门禁未通过时不启动深度训练。未达到晋级规则时立即停止，不自动追加随机种子、模态组合或结构变体。
