# BUS+Text 主干与 SWE 残差成对实验设计

## 目标

在现有固定划分下，尽快判断轻量 SWE 注入能否稳定改善恶性四分类，尤其是 Luminal B 与 TNBC。该实验只检验一个结构改动，不把单次测试集波动写成论文增益。

## 模型与对照

沿用 Stage 2 的 TinyUSFM、文本分支、融合模块与分类头。两组均使用 BUS 与文本作为主干：联合切片嵌入层的 SWE 通道固定输入零张量，不运行 CDFI 分支或 IP-Adapter。实验组额外把真实 SWE 输入交给轻量 CNN，经投影和有界可学习系数加到 BUS 图像特征上，然后进入同一个 BUS+Text 融合模块。对照组没有 SWE 分支。两组共用预训练初始化规则、训练参数、数据划分和评价代码。

新增模式仅支持 `flat5`，与既有 B1 实验的训练目标保持一致；恶性条件四分类仍使用前四类 logits 评价。旧模型保持默认结构与检查点兼容。

## 最小实验协议

1. 固定训练、验证和测试病例 ID，为成对模式使用独立且同 seed 的 DataLoader 随机流；训练阶段只以恶性验证集 Macro-F1 选择检查点，两种新模式训练结束时不自动评估测试集。
2. seed 42 先成对训练两组；比较验证集 Macro-F1、Balanced Accuracy、逐类 F1/Recall、混淆矩阵和预测分布。只有残差组的 Macro-F1 与 Balanced Accuracy 均高于对照，且没有把原本非零召回的类别压到零，才补另外两个种子；否则记录负结果并停止扩展。
3. 若 seed 42 有明确改善，再以相同设置补 seed 3407 和 2026。只有多种子验证结果方向一致、关键类别没有持续塌缩时，才通过检查点复评入口对锁定模型做测试集比较与 SWE 病例置乱审计。
4. 远端训练、缓存、权重、逐例审计均写入 `/data`；本地只提交代码、测试和脱敏汇总。不得覆盖现有远端探针目录中的未提交文件。

## 解释边界

82 例测试集和单次置乱不足以证明临床泛化或 SWE 因果贡献。若验证指标与测试指标冲突，论文结论以预先固定的验证门槛和如实披露的测试结果为准；不能根据测试集结果反复调模型。
