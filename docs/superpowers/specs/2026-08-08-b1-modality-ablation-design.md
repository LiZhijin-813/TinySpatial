# B1 两阶段模态消融实验设计

## 1. 实验目的

当前 B1 在二分类任务上具有较好的区分能力，但恶性四分类出现明显类别塌缩：Luminal B 和 TNBC 召回率为零，预测主要集中到 HER2+ 和 Luminal A。病例级审计已经确认，82 个恶性测试病例的标签、顺序和 BUS、SWE、CDFI、文本文件存在性没有异常。

本实验不立即改变模型结构，先回答两个问题：

1. 完整 B1 检查点在推理时依赖哪些模态；
2. 不同模态组合单独训练时，哪些组合真正有助于恶性四分类。

## 2. 总体协议

实验分为两个阶段。

### 阶段 A：固定检查点的模态依赖诊断

加载固定 B1 检查点 `flat5_20260731-232334/best_model.pth`，保持模型参数、病例顺序和所有评价代码不变，仅在输入模型前屏蔽一个模态或一组模态。

诊断组合包括：

- 完整四模态：BUS、SWE、CDFI、文本；
- 去除 BUS；
- 去除 SWE；
- 去除 CDFI；
- 去除文本。

该阶段只用于诊断模型依赖性，不把屏蔽后的结果作为正式单模态性能结论。所有组合使用同一检查点和同一恶性测试集，输出到 `/data/lzj813/b1-modality-probe-20260808`。

### 阶段 B：固定切分的独立训练消融

对每个候选模态组合分别训练模型，训练集、恶性验证集、恶性测试集、二分类验证集和二分类测试集均恢复自 B1 的 `split_manifest.json`。除模态组合和对应的输入屏蔽配置外，保持以下设置不变：

- 任务：`flat5`；
- 随机种子：第一轮使用 42；
- 图像尺寸、批大小、学习率、权重衰减、训练轮数、早停和解冻层数；
- 预训练权重、类别权重、采样方式和模型选择指标；
- 训练、验证和测试病例 ID。

第一轮候选组合为：

| 组合 | 保留模态 | 目的 |
| --- | --- | --- |
| BUS-only | BUS | 评估解剖结构单独提供的分型信息 |
| BUS+SWE | BUS、SWE | 评估几何对齐的结构—硬度组合 |
| BUS+CDFI | BUS、CDFI | 评估结构—血流组合 |
| BUS+文本 | BUS、文本 | 评估结构—语义组合 |
| 四模态 | BUS、SWE、CDFI、文本 | 复现 B1 完整模型并作为对照 |

阶段 B 的正式结果输出到 `/data/lzj813/b1-modality-ablation-20260808`，每个组合使用独立子目录。

## 3. 模态屏蔽定义

为避免不同实验使用不同的缺失模态语义，所有屏蔽操作统一在输入进入模型前完成：

- 图像模态：使用与当前数据预处理一致的零值张量，保持批次形状和归一化后的数值域不变；
- 文本模态：使用全零 `input_ids` 和全零 `attention_mask`，表示没有有效文本 token；
- 保留模态：完全沿用现有数据集读取、归一化、尺寸变换和文本编码流程。

阶段 A 与阶段 B 使用同一屏蔽函数，避免“推理诊断”和“重新训练”实际上使用不同的数据处理。

该定义不模拟真实临床缺失数据，只表示受控的模态移除实验。结果只能解释为模态信息贡献或模型依赖性，不能解释为缺失模态场景下的临床性能。

## 4. 评价指标

主要判据按优先级排列：

1. 恶性条件四分类 Macro-F1；
2. 四个亚型的 Recall，特别关注 Luminal B 和 TNBC 是否摆脱零召回；
3. Balanced Accuracy；
4. 混淆矩阵和预测分布。

二分类 AUC、二分类 Macro-F1 和端到端五分类指标作为辅助指标，不能替代恶性条件四分类指标。

阶段 A 主要比较相对完整四模态的指标变化和预测分布。阶段 B 只有在验证集上达到以下条件时才进入多种子复验：恶性条件 Macro-F1 高于 B1 单种子基线 `0.2329`，且四类验证召回均非零，或至少明确改善 Luminal B/TNBC 且没有造成整体指标明显下降。

## 5. 实验完整性与输出

每个阶段和每个组合必须保存：

- 实验参数 JSON；
- 固定切分清单或其哈希；
- 测试指标 JSON；
- 恶性四分类混淆矩阵、四类召回和预测分布；
- 屏蔽模态列表；
- 运行日志和失败原因。

临时缓存、模型权重和实验输出全部放在远端 `/data`，不写入根分区，也不将大模型权重提交到 Git。代码修改提交到 `exp/reliable-stage2-baselines`，实验结果文档单独记录。

## 6. 风险与限制

1. 现有元数据没有患者级 ID。良性数据中存在 13 个涉及测试集的疑似前缀跨 split 组，因此二分类和端到端五分类结果需要保留数据划分风险说明。
2. 阶段 A 的屏蔽推理存在训练—测试分布偏移，只用于依赖性诊断。
3. 如果阶段 B 的模态屏蔽实现引入新的训练行为，必须先用固定小样本测试确认输出形状、标签路径和损失计算不变，再启动远端训练。
4. 在消融结果明确前，不引入新的跨模态融合模块、对比学习目标或额外类别重平衡策略。
