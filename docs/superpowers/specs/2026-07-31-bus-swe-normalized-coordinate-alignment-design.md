# BUS-SWE 归一化坐标对齐设计

## 背景

Stage 2 公平 B0/B1/B2 首次运行时，部分病例的 BUS 与 SWE 原始像素尺寸不同，例如 BUS 为 `310×380`、SWE 为 `368×372`。现有确定性配对变换将原图尺寸完全相同视为前提，导致 DataLoader 在第一个不匹配病例处中断，三组基线均未产生指标。

本项目的空间先验是“同一病例 BUS 与 SWE 在解剖视野的归一化坐标上对应”，而不是“两个导出文件的像素矩阵尺寸必须相同”。因此，原始尺寸不一致不应被视为病例配对错误。

## 方案

BUS 与 SWE 分别缩放到相同的中间尺寸，再执行共享的空间变换：

1. 训练阶段：分别等比例缩放到可支持随机裁剪的公共中间画布；随后对两模态使用同一组裁剪坐标、翻转开关和旋转角度。
2. 评估阶段：分别缩放到相同的 `img_size×img_size` 归一化坐标网格，不使用随机变换。
3. CDFI 保持既有独立变换，不把它错误地当作严格几何对齐模态。

这保留了 BUS-SWE 在归一化视野中的共享几何关系，同时消除了导出分辨率差异造成的人工阻断。

## 不采用的方案

- 直接丢弃尺寸不一致病例：会无依据地减少样本并改变既定公平划分。
- 对 BUS/SWE 使用各自独立的随机裁剪、翻转或旋转：会破坏本研究依赖的空间对应先验。
- 通过 ROI 裁剪重新配准：与当前“无 ROI 数据”的研究约束冲突。

## 验收条件

- 原始尺寸不同的 BUS/SWE 可在训练和评估阶段稳定产生相同输出尺寸。
- 同一随机种子下，训练配对变换仍对两模态使用同一几何参数。
- 评估变换保持确定性。
- 原有尺寸相同样本行为不回归。
- B0、B1、B2 能完整启动并写出 `metrics_test.json`，之后再核验三个 `split_manifest.json` 的恶性验证/测试 case ID 一致。

## 风险与记录

该修改只改变数据导出分辨率的处理方式，不声明原始像素级配准。论文中应表述为“归一化坐标共享几何增强”，并在实验记录中保留此前三组基线因尺寸断言失败而未产生指标的事实。
